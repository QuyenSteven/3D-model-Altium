# KF141R-2.54 pin-layout baseline

Source family: KEFA / Cixi Kefa Electronics KF141R-2.54 right-angle spring terminal block.

Reference evidence:
- Manufacturer drawing KF141R-2.54-XXP-1X: pitch 2.54 mm, PCB holes Ø1.2 mm, 5.08 mm spacing between the two PCB pin rows, rear-row relation approximately 3.0 mm to the housing edge.
- LCSC C475124..C475132: exact 2P..10P family.
- Exact EasyEDA STEP C475132 (10P) was fetched into `reference_models/KF141R-2.54/` and sectioned below the PCB plane.

## Canonical PCB-critical coordinates

For an N-pole model:
- Housing length X = `(N+1) * 2.54 mm`.
- Pole pitch X = 2.54 mm.
- Two THT pins per pole.
- Front solder-pin row center Y = **-1.053145 mm**.
- Rear solder-pin row center Y = **+4.027003 mm**.
- Row spacing = **5.080148 mm**.
- Rear row is **2.872997 mm** from the +Y/rear housing edge (drawing nominal 3.0±0.3 mm).
- Pin main section ≈ **0.50 x 0.70 mm**.
- Tail bottom = **Z=-3.50 mm**.
- First pole center = **0.95 mm from the LEFT housing edge**.
- The pole/pin array is intentionally **not centered** in the overall housing length.

Example 10P:
- Housing X = 27.94 mm.
- Pole centers run from X=-13.02 to +9.84 mm.
- First-to-last pole span = 22.86 mm.

These coordinates override visual symmetry. Do not re-center the pin array in future revisions.
